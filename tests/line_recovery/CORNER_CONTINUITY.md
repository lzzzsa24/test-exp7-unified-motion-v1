# 外侧见线后继续转向，进入中间区域再接线

用户最新观察：塑料布上，弯道微转后外侧识别黑线便不再转，布面回弹带偏车辆，
再次全白又微转，循环往复；没有留意蜂鸣是否同步启停。
本轮以该观察为主要问题，不将布面起皱单独视为根因。

## 核对结果和边界

已部署集成源码 `eaa4b38cdaa1b852976cf79e89fdc8536ec5d29a` 与本 worker 父提交
`435e6e2fd6eba2393c5af0831b11afbce8946cda` 的寻线/恢复/驱动文件相同。
集成工作树 HEAD `f9ab71d`、状态检查 OK；本轮只在独立 worker 编辑。

代码中的外侧单独见黑并不会在已经开始的搜索中直接停车。因此不能把用户所说的
“外侧见线”直接当成某个已证实的 if 分支，仍缺少测试时四路原始位和状态时序。
但有两条明确的软件路径：

- 正常急弯先 120 ms 同向差速，再原地对转到 280 ms，之后改回同向圆弧，即使外侧
  仍持续压线。旧代码新增回归在左外侧保持 600 ms 后输出 +2100/+3300（测试中的
  PWM 等价 CPS），与“保持对转直到真正接线”的要求不符，测试返回 1。
- 搜索中任何内侧一帧见黑（包括同侧外侧+内侧组合）都会先制动，再停车确认。
  短暂接触便能撤掉转向输出；低速接线退回外沿时旧代码也只给弱差速前进。

以上反例证明控制逻辑存在提前退出强转向的路径，不证明这是现场唯一原因。
本轮不连接串口/COM11、不复位、不烧录、不移动小车，也不修改 PROJECT_STATE.md。

## 现在的规则

| 阶段/输入 | 动作 |
|---|---|
| 正常或低速接线，左外侧单独/左外侧+左内侧见黑 | 锁定左转，进入持续转向 |
| 右侧对应情况 | 锁定右转，进入持续转向 |
| 持续转向时外侧、同侧双探头、全白来回变化 | 保持原方向和对转目标，不重新制动或重启计时段 |
| 内侧见黑，但任一外侧仍见黑 | 仍视为边缘，继续转向 |
| 外侧均白，至少一个内侧连续见黑 20 ms | 开始制动，再停车确认 20 ms |
| 确认成功 | 进入至少 500 ms 的低速接线，中间稳定 80 ms 后恢复正常 |
| 停车确认失败 | 80 ms 窗口后继续原方向转向，不锁存停车 |
| 低速接线退回单侧外沿 | 直接恢复持续转向，不等待全白再刹车搜索 |
| 操作员 STOP/模式 reset | 原有取消路径保持有效 |

删除正常急弯的 120/280 ms 分段定时和重复的左右急弯输出分支，复用现有恢复状态机。
从在线外沿进入转向不额外插入停车；由原 DriveBase 目标斜坡处理轮子换向，斜坡过零
可能短暂为零，这不是传感器反复切换导致的停车锁存。

在线急弯不自动鸣响；进入全白后开始循环预制蜂鸣，并持续到确认接线。
普通丢线入口的初次制动保留；外侧/全白抖动发生在持续转向中，不反复回到该入口。

急弯统一使用现有搜索配置：默认同侧等幅、左右反向 2493 CPS，对照 1870 CPS。
替代旧短时 3000 PWM（实际约 5273 CPS，KEY1 还可增益）的急弯对转段；浅弯的增益
和普通寻线速度不变。不是提高 PWM 上限：上一轮无计数保留助力、方向/信号降级、
日志、500 PI/600 助力/3599 输出上限均保持。

中间确认是工程阈值，不保证实际车身航向已经对正；宽黑带、探头安装高度或实体
灵敏度使外侧一直见黑时，可能一直转向。已转向中的全黑不判捕线，正常直行遇宽线
仍沿用旧宽线策略。四轮滑移和布面回弹的真实结果需集成后实测。
