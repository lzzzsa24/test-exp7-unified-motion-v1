# 寻线驱动异常只记录，保持通电后导出

本轮接续 `3fcf4def68df5ea10023961e1a9fe27defb3efd1`。用户要求驱动故障不让小车
停下，而是记录后交给 AI 分析；并明确读取前保持通电，无须断电保存。

## 运行行为

- 正常寻线和持续丢线搜索显式启用观察策略。原来的 1600 ms 无响应、120 ms 换向
  宽限后 3 次反向周期、连续 3 周期每周期至少 6 次非法 AB 跳变，保留原判定门槛。
- 达到门槛时先保存四轮快照，不进入 DriveBase 故障制动，不产生故障锁存黄灯/声数报警。
  `GetFaultMask()` 继续只代表阻断故障；观察记录通过独立日志和 `DEG` 状态公开。
- 只有方向或信号判定异常的轮子在当前寻线运行期间使用原 CPS/PWM 标定换算、已有电压补偿和该轮
  连续驱动 PWM 下限，仍受 3599 硬件上限约束。它不再使用可疑反馈追加 PI、负载辅助
  或重复启动补偿。其他轮保持原有速度闭环；目标方向和寻线目标速度不修改。
- 单独的无计数事件仍记录，但保留原有限幅 PI 和转弯助力，避免高阻力地面上的轮子
  在 1600 ms 后突然减力。无计数也可能来自断开的编码器，不能据此确认只是机械负载；
  相关输出依旧受 3599 上限约束。细节见 [负载下保持转弯助力](TURN_EFFORT_RETENTION.md)。
- 停车、切换模式重置观察策略和降级标志，但保留日志。位置动作主动撤销观察策略，
  非寻线速度动作默认仍保留原故障停车。阻断故障不会被本接口自动清除。
- 原遥控 0 停止优先级、上电 STOP、KEY1 避障接管、KEY3/4 定位模式不改变。
- 丢线预制蜂鸣仍循环；确认捕线后静音恢复。此次三类观察事件不替换预制蜂鸣。

这是继续发出电机指令，不保证卡住的实体轮子会重新转动。异常轮退出闭环后轮速精度
降低，真正受阻仍可能持续通电，实际车身偏移和电机负载未经本轮测试。

## 记录格式和保留范围

固定 32 条 RAM 环形记录。持续相同故障组合且间隔小于 1 秒时合并，保留首次完整快照，
更新末次时间和触发次数；故障组合变化或超过间隔产生新记录。满后覆盖最旧记录，
导出 `overwritten` 数量。时间为本次上电毫秒，允许 uint32 回绕，非日历时间。

遥控停止、切换模式、`DriveBase_ClearFault()`、重复读取均不清日志。
复位、断电、重新初始化 DriveBase 会清日志；不要在读取前重新烧录。
记录只写 RAM，不写 Flash、不占用校准页，不执行现场串口输出。

`LFAULT BEGIN` 后，每条事件有一行元信息和四行车轮数据，最后 `LFAULT END`。
串口已有 DRV/BAT 等文本可能穿插，提取所有 `LFAULT` 行即可。途中启动小车会暂停
导出，下一次操作员停车后从新的 BEGIN 重新导出，分析时取最后一个完整块。

| 字段 | 含义 |
|---|---|
| `seq` | 环形日志全局事件序号，用于排序，不按回绕后的时间值排序 |
| `first_ms/last_ms/hits` | 首次/末次触发时刻、合并的触发周期次数 |
| `dt` | 触发周期实际间隔，正常约 20 ms，判断是否存在主循环延迟 |
| `stall/direction/signal` | 三类异常各自的轮号位掩码，1/2/4/8 对应 M1/M2/M3/M4 |
| `sensors` | 最近一次寻线输入，1/2/4/8 对应 X1/X2/X3/X4；物理左到右 X2/X1/X3/X4 |
| `recovery` | 最近一次寻线状态：0 正常、1 搜索、2 低速接线、3 阻断停车 |
| `degraded` | 本次寻线已改用基础 PWM 的轮号位掩码 |
| `mv` | 当时缓存的电池毫伏，0 表示没有有效读数 |
| `wheel` | 1 左前、2 左后、3 右前、4 右后 |
| `requested/controlled/measured` | 请求轮速、斜坡后的控制轮速、测得轮速，单位 CPS |
| `pwm` | 触发判定前已经施加的有符号 PWM，不是下一周期降级后的输出 |
| `delta/illegal/zero_ms` | 本周期有符号编码器增量、非法 AB 跳变增量、无计数累计毫秒（最多 1600） |

方向和信号事件只是软件判定，不证明硬件损坏；保留数据用于区分真实反转、轮子回弹、
无反馈和异常采样。首次快照不含完整事件前的连续轨迹，合并期间各轮的变化也不逐帧保留。

## 之后如何交给 AI 读取

1. 测试后用遥控 **0** 停车，保持小车供电，不按复位、不进入下载模式。
2. 再次连接串口后，告诉 AI：“保持停车，只读取寻线故障日志”。正常应用串口为
   **115200、8N1**，不是烧录波特率。枚举当时端口，不写死 COM11；连接时避免 DTR/RTS 复位。
3. 发送单个 ASCII **`f`**（大写 `F` 也支持），保存 `LFAULT BEGIN` 到 `LFAULT END` 的
   完整文本。该命令不启动运动，不清记录；若尚未停车，只排队等待操作员停车。
4. AI 可用 `stall/direction/signal` 区分原因，结合 `dt/delta/illegal/pwm` 分析；不要只看
   旧蜂鸣声数或把模拟故障测试当成现场原因。必要时可再次发送 `f` 获取同一记录。

`DRV DEG=n LOG=n` 为实时简略状态；`DEG=0` 仅说明当前未降级，不表示历史日志为空。
