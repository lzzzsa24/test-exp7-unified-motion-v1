# 简化四路寻线

本分支从硬件接口和已记录的电机标定数据重新编写应用。唯一控制链路是：
四路 GPIO → 两次一致采样 → 左右侧 PWM → 四个电机。
无 RTOS，无速度/位置闭环，无回退轨迹；所有运行判断都在固定 5 ms 周期内完成。

分支：`feature/simple-four-line`。起点：`d2efe0e`。
回退标签：`rollback/2026-09-05-before-simple-four-line`。

## 使用

以下按键定义适用于**新固件**，本次尚未烧录，板上仍是旧版综合程序。

| 输入 | 操作 |
|---|---|
| 上电、复位 | 停车，按住启动键上电也不会启动 |
| 实体 KEY1 或 KEY2 | 按下启动寻线；启动时全白则保持停车 |
| 实体 KEY3 | 停车，按住时优先于所有启动来源 |
| 遥控器数字 1 / 2 | 启动；NEC 长按重复帧不重新启动 |
| 遥控器数字 0 / 3 | 停车 |
| 串口字符 `1` / `2` | 启动 |
| 串口字符 `0` / `3` / `s` / `S` / 空格 | 停车 |
| 串口 `?` | 查询状态 |

串口为 USART1，PA9 TX / PA10 RX，115200、8N1。连接前枚举实际串口号。
遥控/实体/串口没有不同驾驶模式；KEY3 已不再执行八字。
自动停车后不会因再次看见黑线自行恢复；需松开按键，再明确启动。

## 决策表

四位始终按车头朝前时的**左外、左内、右内、右外**排列：`X2 X1 X3 X4`。
`1` 表示检测到黑线（引脚低电平），`0` 表示白底。
左右侧各两台电机接收相同逻辑 PWM，负数表示该侧倒转。

| 四路读数 | 动作 | 左 PWM | 右 PWM |
|---|---|---:|---:|
| `0110` | 居中直行 | 2400 | 2400 |
| `0100` | 向左微调 | 2200 | 2600 |
| `0010` | 向右微调 | 2600 | 2200 |
| `1000`、`1100` | 左急转 | -2700 | 2700 |
| `0001`、`0011` | 右急转 | 2700 | -2700 |
| `0000`，最近有方向依据 | 沿最近方向原地搜线 | 按方向取 ±2700 | 与左侧反向 |
| `0000`，没有近期方向依据 | 已在行驶时允许跨越最多 60 ms 的短间隙，随后停车 | 2200 | 2200 |
| 其余 8 种组合 | 宽线/交叉/分离检测，短时直行通过；持续 300 ms 则停车 | 2200 | 2200 |

急转和搜线共用 **900 ms** 截止时间，不能靠瞬间碰线或重复启动命令延长。
探头回到中间即停止反转并恢复差速控制；中间读数持续 30 ms 后结束本次恢复。
恢复确认期间 `0110` 使用 2200，确认后恢复 2400。
普通直行超过 250 ms 没有新的左右偏差信息后，旧方向不再用于新的丢线搜索。
单次噪声不触发转向；连续 50 ms 无法形成两次一致采样则停车。

电机换向时先输出零，再等待至少 10 ms 才允许反向通电。
正常停车是 PWM 归零滑停，不代表机械瞬停。
主控制间隔超过 50 ms 会锁存停车；主循环完全卡住则由独立看门狗复位回 STOP
（LSI 40 kHz 时名义约 200 ms，实际随片内振荡器变化）。

## 查看运行状态

USART1 每 200 ms 上报一次，状态切换和查询也尝试上报；发送繁忙时丢弃遥测，控制不等待串口。

```text
SL1 TRACK OK raw=0110 line=0110 L=2400 R=2400
SL1 SEARCH OK raw=0000 line=0000 L=-2700 R=2700
SL1 STOP LOST raw=0000 line=0000 L=0 R=0
```

`raw` 是原始读数，`line` 是滤波后读数；`L/R` 是换向间隔和限幅后的逻辑 PWM，
不是编码器测速值，逐轮实际 CCR 还会经过标定映射。
停车原因：`USER` 手动，`NO_LINE` 启动无黑线，`LOST` 丢线，`TURN_TIME` 转向超时，
`WIDE_TIME` 宽线超时，`LOOP_TIME` 主循环超时，`NOISY` 输入持续不稳定。
UART 接收溢出或帧错误也会请求停车。

LED1（PG13）表示运行，LED2（PG15）表示自动停车故障。
左右 RGB 的红/绿分量分别映射到本侧外/内探头，停车时也更新，便于移动黑纸核对接线。
状态原因变化会短鸣 100 ms。本版不刷新 OLED，不采集电池、编码器或障碍传感器。

本次**未烧录、未悬空试车、未地面试车**。PWM=2200/2400/2700 是参考历史悬空
硬件数据选取的初始值，不是本程序地面验收结果。后续经明确授权烧录后：

1. 停车时逐一遮挡探头，核对左到右 `1000 → 0100 → 0010 → 0001`。
2. 悬空核对启动、左右急转的电机方向和 KEY3/遥控 0 停车。
3. 在同一地面、电池电压下测试直线、左右弯、丢线和宽线；记录 `SL1` 停车原因。
4. 只根据真实表现调整 `line_config.h`：急转起不来调转向 PWM，冲过线则降低速度；
   首先核实探头阈值和安装位置，再考虑增加控制逻辑。

适用目标是白底黑线的连续循迹。本版对岔路短时直行，不执行路线规划或避障。
